How to use this page
  1. Take one fix at a time, on its own branch. Paste its prompt into Claude Code with these docs in docs/ (handbook = index.html).
  2. A fix is done only when every “Done when” line is true. Check them yourself before you mark it.
  3. Update the status here (on the card and in the JSON at the bottom): To do → In progress → Done, or Blocked with a reason. Record doc changes in the changelog.
  4. If a fix disagrees with the handbook, the handbook wins. Ask Poonam or Shikha; don't ask the client.
